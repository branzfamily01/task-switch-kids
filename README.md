# TASK SWITCH - Garage Quest

興味がわかない課題を「始められる形」に変換する、子ども向け行動起動アプリです。

## Garage Quest v3

男の子向けのレーシング／ガレージUIへ全面改修しました。

### 新しい導線
1. **MISSIONを選ぶ**
2. アプリが今のコンディションから**作戦を1つ推薦**
3. **「この作戦でスタート」**で決定
4. 進まない場合だけ**「別の作戦に変える」**
5. 完了するとXPを獲得し、スーパーカーをアンロック

STARTとSWITCHを同列に並べず、決定と作戦変更の役割を明確に分離しています。

## スーパーカー・ガレージ
XPで以下のマシンが順番にアンロックされます。

- McLaren Speedtail
- Mercedes-AMG GT R
- Toyota 86
- Toyota Sprinter Trueno
- Nissan GT-R
- Ferrari F40
- Porsche 911 GT3
- Lamborghini Aventador

車両画像は外部画像に依存せず、アプリ内SVGで表示します。

## タイマー
「3分タイマー」「2分タイムアタック」を選んだ場合、その作戦画面内にオンボードタイマーが表示されます。

- START
- PAUSE
- RESET
- 終了時表示・対応端末ではバイブレーション

RESCUE MODEの「2分だけ」でも同じタイマーを利用できます。

## タスク管理
- 初期サンプルタスクは表示しません。
- 旧バージョンから移行する際は、既知のサンプルだけ除去し、ユーザーが入力したタスクは引き継ぎます。
- 各ミッションは個別に削除できます。
- データは `localStorage` に保存されます。
