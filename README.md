# TASK SWITCH

興味がわかない課題を「始められる形」に変換する、子ども向け行動起動アプリのMVPです。

## 主な機能
- 今日のミッション
- エネルギー状態（疲れた／普通／元気）
- START：状態に応じて開始戦略を選択
- SWITCH：進まないときに作戦変更
- やる気ゼロモード
- 着手・完了XPと宝箱
- 親向けダッシュボード
- 興味・反応タイプ設定
- ローカル保存（localStorage）
- PWA / オフライン対応

## GitHub Pages公開
1. ZIPを解凍します。
2. 解凍後の `index.html`、`app.css`、`app.js`、`manifest.webmanifest`、`sw.js`、`icons/`、`README.md` をそのままリポジトリ直下へアップロードします。
3. GitHub Pagesの公開元を `main` ブランチの `/ (root)` に設定します。

推奨リポジトリ名: `task-switch-kids`

## 注意
このMVPは医療機器・診断ツールではありません。行動開始を支援するための一般的なタスク設計アプリです。
